# MVP Stock Sync (ส่วนขยาย Chrome)

อัปเดตคลังร้าน Shopee **mvp.sport2023** (shop_id 1423805168) จาก ST ทุกวัน 18:00 หรือกดเอง

ร้านนี้ผูก API ของ Shopee ไม่ได้ (ต้องเป็น Managed/Mall) ส่วนขยายจึงทำแทนคนผ่านหน้า "แก้ไขข้อมูลสินค้าแบบชุด"
ของ Seller Center: สร้างไฟล์ "แก้ไขสินค้า" → ดาวน์โหลด → เติมคลัง → อัปโหลด

คลังมาจาก `POST /api/mvp/stock` ของเว็บ order-sync: **ST − ออเดอร์รอส่งทุกร้าน, เหลือ ≤ 2 ลง 0**
SKU ที่ไม่มีใน ST คงค่าเดิม (รายงานจำนวนไว้) ผลแต่ละรอบส่งเข้า Telegram ผ่าน `POST /api/mvp/report`

## ติดตั้ง (ครั้งเดียว)

1. Netlify → order-sync → Environment variables เพิ่ม `MVP_STOCK_KEY` = ข้อความสุ่มยาวๆ (ตั้งแบบธรรมดา ไม่ใช่ secret) → Trigger deploy
2. เปิด Chrome **โปรไฟล์ที่ล็อกอิน mvp.sport2023** → `chrome://extensions` → เปิด Developer mode
3. Load unpacked → เลือกโฟลเดอร์นี้ (`extensions/mvp-stock`)
4. กดไอคอนส่วนขยาย → ตั้งค่า → วางกุญแจเดียวกับข้อ 1 → บันทึก

## เงื่อนไข

- Chrome โปรไฟล์นั้นต้องเปิดอยู่ตอน 18:00 (ถ้าปิดอยู่ จะทำรอบที่พลาดทันทีที่เปิด Chrome)
- ต้องล็อกอิน Seller Center ร้าน MVP ค้างไว้ ถ้าหลุด รอบนั้นหยุดและแจ้งเตือน
- ไม่ทำงานถ้า: ร้านไม่ใช่ 1423805168 · ไฟล์ ST เก่าเกิน 48 ชม. · จะเปลี่ยนเกินครึ่งของแถว · หัวคอลัมน์ของแบบฟอร์มเปลี่ยน

## ถ้าพัง

คำขอเบื้องหลังของ Seller Center ไม่ใช่ API ที่ Shopee รับรอง ถ้าหน้าเว็บเปลี่ยนอาจใช้ไม่ได้
รายละเอียดคำขอที่ใช้อยู่ใน `background.js` หัวไฟล์
