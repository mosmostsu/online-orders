# MVP + PACE Stock Sync (ส่วนขยาย Chrome)

อัปเดตคลังร้าน Shopee ที่ไม่มี API จาก ST เมื่อกดปุ่มในส่วนขยาย (ไม่มีรอบอัตโนมัติ) ทำกับร้านที่ล็อกอิน Seller Center อยู่:

| ร้านในระบบ | ชื่อบน Shopee | shop_id |
|---|---|---|
| MVP | mvp.sport2023 | 1423805168 |
| PACE | PACEsports | 1935942975 |

เพิ่มร้านใหม่: เพิ่มใน `SHOPS` ของ `background.js` + `SHOPEE_NO_API` ใน `lib/shopGroups.js` · โคลนจาก TikTok ใช้ได้เฉพาะร้าน MVP

ร้านพวกนี้ผูก API ของ Shopee ไม่ได้ (ต้องเป็น Managed/Mall) ส่วนขยายจึงทำแทนคนผ่านหน้า "แก้ไขข้อมูลสินค้าแบบชุด"
ของ Seller Center: สร้างไฟล์ "แก้ไขสินค้า" → ดาวน์โหลด → เติมคลัง → อัปโหลด

คลังมาจาก `POST /api/mvp/stock` ของเว็บ order-sync: **ST − ออเดอร์รอส่งทุกร้าน** (ติดลบ = 0 · ไม่กันชิ้นสุดท้าย)
SKU ที่ไม่มีใน ST คงค่าเดิม (รายงานจำนวนไว้) ผลแต่ละรอบส่งเข้า Telegram ผ่าน `POST /api/mvp/report`

ทุกรอบส่งรายการสินค้าทั้งร้านจากไฟล์เดียวกันเข้า `POST /api/mvp/listings` ด้วย → หน้า `/product` และ `/allsite`
แสดงร้านนั้น (นับทุกตะกร้าเป็น "ขายอยู่" เพราะไฟล์ไม่บอกสถานะ) ต้องรัน `supabase/049` ก่อน

## ดึงออเดอร์เข้าหน้ารอบจัดส่ง (1.3+)

ร้านพวกนี้ไม่มี API หน้า `/round` เลยไม่มีใบจัดของ ของที่ยิงออกใน Seniorsoft (ลูกค้า Shopee) ตกไปเป็น "ของเกิน"
กด **ดึงออเดอร์** วันละครั้งหลังกดจัดส่ง (ร้านกดส่งวันละรอบ) — ปุ่มอยู่ในหน้าต่างส่วนขยาย และในหน้า `/round`
- เครื่องที่ติดตั้งส่วนขยาย: ปุ่มในหน้า /round ดึงตรงๆ
- เครื่องอื่น (1.4+): ปุ่ม "ขอดึงออเดอร์" ฝากคำขอไว้ (`os_mvp_pull`, supabase/070) ส่วนขยายถามเว็บทุก 2 นาที (07:00-21:00)
  แล้วดึงให้ · Chrome เครื่องนี้ต้องเปิดอยู่ · หลุดล็อกอิน/ล็อกอินร้านอื่น → หน้าเว็บบอก + แจ้ง Telegram

อ่านแท็บ "ที่ต้องจัดส่ง" ทั้งหมด + กำลังจัดส่ง/สำเร็จ/ยกเลิก หน้าแรก (เฉพาะใบไม่เกิน 7 วัน) อ่านอย่างเดียว ไม่กดอะไรบนร้าน
→ `POST /api/mvp/orders` → `os_orders` ตารางเดียวกับร้านอื่น · เวลาแบ่งรอบ = เวลากดจัดส่งจริงจาก Seller Center
ใบ "แพ็คแล้ว" ของร้านนี้ไม่ขึ้นในสรุป "ค้างในกอง" ตอนเย็น (ดึงวันละครั้ง ไม่รู้ว่าขนส่งรับไปหรือยัง)

## ติดตั้ง (ครั้งเดียว)

1. Netlify → order-sync → Environment variables เพิ่ม `MVP_STOCK_KEY` = ข้อความสุ่มยาวๆ (ตั้งแบบธรรมดา ไม่ใช่ secret) → Trigger deploy
2. เปิด Chrome **โปรไฟล์ที่ล็อกอินร้านนั้น** (ทำทีละโปรไฟล์) → `chrome://extensions` → เปิด Developer mode
3. Load unpacked → เลือกโฟลเดอร์นี้ (`extensions/mvp-stock`)
4. กดไอคอนส่วนขยาย → ตั้งค่า → วางกุญแจเดียวกับข้อ 1 → บันทึก

## เงื่อนไข

- ต้องล็อกอิน Seller Center ของร้านค้างไว้ ถ้าหลุด รอบนั้นหยุดและแจ้งเตือน
- ไม่ทำงานถ้า: ร้านไม่อยู่ในตารางด้านบน · ร้านเปลี่ยนระหว่างทำงาน · ไฟล์ ST เก่าเกิน 48 ชม. · จะเปลี่ยนเกินครึ่งของแถว · หัวคอลัมน์ของแบบฟอร์มเปลี่ยน

## ถ้าพัง

คำขอเบื้องหลังของ Seller Center ไม่ใช่ API ที่ Shopee รับรอง ถ้าหน้าเว็บเปลี่ยนอาจใช้ไม่ได้
รายละเอียดคำขอที่ใช้อยู่ใน `background.js` หัวไฟล์
