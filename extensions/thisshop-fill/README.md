# ThisShop Fill (ส่วนขยาย Chrome)

เติมตัวเลือก (สี/ไซส์) ที่ตะกร้า **ThisShop** ขาด ให้เหมือน **Shopee REAL** — กดปุ่ม ➕ ท้ายแถวในหน้า `/compare`
(กลุ่มที่มี Shopee REAL + ThisShop · แถวที่ ThisShop "SKU ไม่ครบ")

ThisShop ไม่มี Open API ที่แก้ตะกร้าได้ (`thisshop.goods.update` ตอบ 40000 ทุกแบบ) ส่วนขยายจึงกดในหน้าแก้ไขสินค้า
หลังบ้าน `sale.thisshop.com` แทนคน ขั้นเดียวกับที่ทำมือ:
แท็บ Sales attribute → พิมพ์ชื่อตัวเลือกใหม่ → Add → อัปรูปสี → ติ๊ก → Generate SKU → ลบแถวที่สร้างเกิน → คลัง → ราคา/รหัส
→ (ติ๊กได้) ใส่ชื่อสินค้าใหม่ + แทนรูปสินค้าทั้งชุดด้วยรูปจาก Shopee REAL (รูปแรก = รูปปก) → Publish

แผน (ตัวเลือกไหน ชื่ออะไร ราคา คลัง รูป) มาจากเว็บ order-sync `POST /api/basket/thisshop-fill` (`lib/thisshopFill.js`)
ส่วนขยายแค่ทำตาม ไม่คิดเอง

## ติดตั้ง (ครั้งเดียว)

1. ใช้ Chrome โปรไฟล์ที่ล็อกอินหลังบ้าน `sale.thisshop.com` ไว้ (ร้าน sc02)
2. `chrome://extensions` → เปิด Developer mode → Load unpacked → เลือกโฟลเดอร์นี้ (`extensions/thisshop-fill`)
3. เปิดหน้า `/compare` ของ order-sync ในโปรไฟล์เดียวกัน (ต้องปลดล็อก PIN ยอดขายก่อน เหมือนปุ่มแก้ตะกร้าอื่น)

## ใช้งาน

กด ➕ (แถวที่ ThisShop ไม่ครบ หรือครบแล้วแต่อยากอัปเดตชื่อ/รูป) → ดูแผน + ติ๊กเลือกชื่อ/รูป → **🧪 ทดลอง** (ทำทุกขั้นแต่ไม่บันทึก แล้วปิดแท็บทิ้ง) หรือ **➕ เพิ่ม** (บันทึกจริง)
บันทึกแล้วเว็บถามตะกร้าสดผ่าน Open API อีกรอบว่า SKU เดิมอยู่ครบ และตัวใหม่ขึ้นครบ

## กันพัง

ไม่บันทึกถ้า: ตะกร้าในหลังบ้านไม่ตรงกับตอนวางแผน · SKU เดิมหาย/ค่าเปลี่ยน · แถวใหม่ไม่ตรงแผนพอดี ·
สถานะขาย/ปิดขายเปลี่ยน · หลังบ้านถามอะไรที่ไม่รู้จัก · หาปุ่ม/ช่องในหน้าไม่เจอ (หลังบ้านเปลี่ยนหน้าตา)

ชื่อตัวเลือกใหม่: ตะกร้า ThisShop ใช้แค่รหัสสี = ใช้รหัสสี · นอกนั้นใช้ชื่อตาม Shopee REAL (จับคู่ด้วย SKU ชื่อไม่ต้องเหมือนแบบเดิม)

ฝั่งวางแผนไม่ทำถ้า: จำนวนชั้นตัวเลือกสองร้านไม่เท่ากัน · ชื่อใหม่ชนกับชื่อที่มีอยู่ ·
สีใหม่ไม่มีรูปทั้งที่ตะกร้าสีมีรูปทุกตัว · ราคาใน Shopee เป็น 0

ถ้าพังกลางทาง แท็บหลังบ้านจะเปิดค้างไว้ (ยังไม่บันทึก) ให้ดูว่าติดตรงไหน ปิดทิ้งได้เลย

## รู้ไว้

- ปุ่ม Generate SKU ของหลังบ้านรวม SKU เดิมที่ซ้ำกันเป๊ะออกจากฟอร์ม แต่บันทึกแล้วของเดิมไม่หาย (บันทึกไม่ลบ SKU ที่ไม่ได้ส่ง)
- หลังบ้านเป็น Vue 2 + Ant Design Vue — ส่วนขยายอ่าน/ตั้งค่าแถว SKU ผ่าน `formData.skuData` ของหน้า ถ้าหน้าเปลี่ยนจะหยุดพร้อมบอกขั้น
